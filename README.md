📱 SMS Spam Classifier — Project Description

SMS Spam Classifier is a Machine Learning project that automatically classifies text messages as Spam or Not Spam (Ham). The project uses Natural Language Processing (NLP) techniques to preprocess SMS text, including tokenization, stopword removal, and stemming. The processed text is converted into numerical features using TF-IDF (Term Frequency–Inverse Document Frequency), which are then passed to a trained machine learning model for prediction.

The project is deployed as an interactive Streamlit web application, where users can enter an SMS message and instantly receive a prediction.

🔧 Technologies Used
Python
Pandas & NumPy
NLTK – Text preprocessing
Scikit-learn – TF-IDF and Machine Learning
Pickle – Saving/loading trained model and vectorizer
Streamlit – Web application
🎯 Key Features
Text preprocessing using NLP
TF-IDF feature extraction
Spam/Ham classification
Interactive Streamlit interface
Fast prediction for user-entered messages
